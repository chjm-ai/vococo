# 项目以「文件夹路径」为身份

我们给 Hermes 引入「项目」(Web 端选一个本地文件夹当 agent 的 cwd,项目下含多个会话)。项目的身份直接**等于其文件夹的规范化绝对路径**——不引入独立的 project id、不支持自定义项目名、不支持同一文件夹开多个项目。会话 key 中以路径的短哈希编码(`web:p<hash>:<conv_id>`),另存一张 `哈希→路径` 小映射表供 UI 显示。

选它是因为单人自用下极简优先:同文件夹天然去重、无需管理 id 生命周期。代价我们明确接受:**文件夹改名或移动 = 项目丢失、其下会话失联**(改回原路径即恢复);显示名只能是文件夹名。若未来要支持重命名/移动仓库不丢历史,需回到「独立 id + path 属性」模型——那将是一次数据迁移。

相关:进入项目后 agent 会自动加载该文件夹自带的 `CLAUDE.md`/`.claude` 配置(叠加在 Hermes 全局人设 + AI_BRAIN 之上),这是「项目 = 带自己上下文的工作根」的应有之义。
