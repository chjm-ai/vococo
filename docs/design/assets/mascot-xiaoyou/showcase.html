复用方式:样式表里「小幽像素引擎」一段 + 脚本里 24×28 基底网格与状态帧生成器整体复制即可,单一像素身深浅底通用。 状态用 .pxfig[data-state] 属性切换——idle / listening / thinking / busy / done / err / sleep / icon, 底层是 JS 从同一基底轮廓派生每帧的 box-shadow 定点列表,并统一引用 var(--pal-p/w/d/k);换色只需切换 <html data-pal>, 不需要重新生成任何关键帧。矢量 SVG + SMIL 版本已下线,全站仅保留像素形态。
