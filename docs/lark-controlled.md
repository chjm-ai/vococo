# 飞书受控入口：图片调用与能力差异

## 已接入的调用

宿主继续使用官方 CLI 的用户认证；写入、上传逐次走 `require_approval`。新参数需进程重启、新回合刷新工具定义后才可用。

1. `lark_document(operation="fetch", doc="文档链接或token", detail="with-ids", scope="keyword", keyword="目标章节")`：获得最新锚点与 revision。
2. `lark_document(operation="insert_image", doc="文档链接或token", image_path="当前业务工作目录内的图片绝对路径", block_id="上一步的块ID", caption="图注", width=640, revision_id=实际版本号)`：在锚点之后插入；`0` 为开头，`-1` 为末尾。可选 height。一次一图；新文档先 create，再插图。
3. `lark_document(operation="update", doc="文档链接或token", mode="block_insert_after", block_id="最新块ID", content="新增 Markdown 段落")`：局部加文字。
4. `lark_document(operation="update", doc="文档链接或token", mode="str_replace", pattern="精确匹配的重复文字", content="")`：删除匹配文字。不能用于替换图片或其他资源。
5. 写后局部 fetch，核验图片 token、图注、位置、尺寸、原有资源和评论；结构变化后重新取块 ID，不盲目重复写入。

图片限制：仅当前会话 workspace 或正式 output_dir；复用成果文件的逐级 NOFOLLOW、路径/秘密检查，拒绝软链、硬链接、隐藏/凭据路径、其他会话目录。仅 PNG/JPEG/WebP，原件与标准化快照均 ≤20MiB，≤2500万像素。保留照片方向、去除元数据，转为 PNG。审批绑定目标、锚点、图注、尺寸、版本和快照 SHA256；批准后只将不可变图片快照放入独立临时目录，官方 CLI 不直接读取业务文件。临时目录自动清理。

局部操作只调用 `block_insert_after` 或 `str_replace`，不把文档抓取后全文重写。它们不会主动替换既有资源块；**真实飞书的资源/评论保留仍须专用文档读回验收，不能仅凭本地测试宣布通过**。用户主动选择 overwrite 仍可能丢失图片、画板和评论，不能作为局部编辑兜底。

### 拦截策略的真实范围

- 旧迁移硬拦截仅针对业务会话的 `docs +fetch/+create/+update`，不是所有飞书命令。本次排除精确的 `--help/-h` 调用，并修补前置 `--profile` 绕过文档路由的缺口。
- 原拒绝文案把策略拒绝断言成钥匙串/TLS故障；本次改为准确的“入口策略拒绝”，不推断凭据状态。
- Drive 等域未被这条迁移规则硬拦，但也没有可用的宿主替代入口；不能把“未拦”视为已认证、能成功执行或已获得写入授权。
- 没有修改其他域的沙箱、认证、TLS 或危险操作审批。权限错误必须来自远端实测；沙箱故障必须来自执行证据；缺入口不能当作权限不足或让用户反复登录。
- 未引入任意 CLI 透传；删除、权限管理、对外发送仍需现有审批，不能以恢复功能为名全面豁免。其他域的逐操作受控入口是后续工作，本次不声称已恢复全部飞书工具。

## 验证与交接

本地：回归覆盖命令生成、审批拒绝零 CLI 调用、批准快照哈希、真实子进程暂存/清理、超时单次调用、路径越界/软链/硬链接/敏感路径、格式/大小/手机方向、帮助及 profile 路由。现有认证串行/TLS错误/取消回收测试继续保留。

上线后的真实验收计划（需重启及既有写入审批）：

1. 只在自己的授权目录生成蓝色/绿色小测试图，不读取其他会话截图。
2. 创建专用测试文档，放“前文/后文/重复文字”并取得块 ID。
3. 插入第一张图，再在前文之后插入第二张带图注/尺寸的图；读回确认真实图片 token、位置与尺寸。
4. 在同文档建立测试画板及评论（若缺受控入口无法建立/读取，应明确未覆盖，不能改用非受控通道），记录已有图片/画板 token、评论；局部文字插入和空字符串替换后比较。
5. 拒绝一次图片审批，读回 revision/正文未变化；超时场景只本地注入，不用真实网络重复写入制造脏数据。
6. 记录服务端 warnings/partial_success；不自动重试不确定写入。不删除测试文档，除非另获删除批准。

本次未操作用户指定的两份 JLL 业务文档，也未读取跨会话 jll-image-pack。Deepleaper 在工具定义刷新并完成验收后，按以上 insert_image 调用继续业务编辑；图片必须从其自身授权目录读取。本地目录和客户材料不公开发布。
